# Logicc vertical slice — manual smoke (credential-safe)

Use only after automated fake-Logicc tests pass under **Node.js 24.x**. Keep the app on **localhost** or another private network. Do not expose port 3000 publicly.

`LOGICC_INTERNAL_MODE=true` is an operator private-deployment flag — **not** authentication.

### Credential source note

Private smoke may use either:

- a Cloud Agent / process environment secret injection, or
- a gitignored local `.env.local` file

Report only which source was used (boolean readiness). Do not claim `.env.local` was tested if it was absent. Never print the credential value.

## 1. Preconditions (boolean checks only)

```bash
# Confirm ignore + untracked — do not print key material
git check-ignore -v .env.local
git status --short
git ls-files --error-unmatch .env.local

# Boolean-only presence (no length/prefix/suffix/hash)
node -e "const fs=require('fs'); const t=fs.readFileSync('.env.local','utf8'); const ok=/^\s*LOGICC_API_KEY\s*=\s*\S+/m.test(t); const bad=/^\s*NEXT_PUBLIC_.*LOGICC/m.test(t); console.log(ok?'LOGICC_API_KEY:configured':'LOGICC_API_KEY:missing'); console.log(bad?'NEXT_PUBLIC_LOGICC:present':'NEXT_PUBLIC_LOGICC:absent');"
```

## 2. Configure Logicc mode locally

The API key alone is insufficient. In gitignored `.env.local` set:

```dotenv
AGENT_PROVIDER=logicc
LOGICC_INTERNAL_MODE=true
LOGICC_ALLOWED_MODELS=<comma-separated enabled model IDs>
LOGICC_DEFAULT_MODEL=<one ID from the allowlist>
LOGICC_API_KEY=<set locally; never commit>
```

### Discover enabled model IDs (sanitized)

Option A — Logicc organization dashboard: copy API model identifiers for models enabled on the account.

Option B — local helper (private only; prints IDs only):

```bash
# Load .env.local into your shell without printing values, then:
npx tsx scripts/discover-logicc-models.ts
```

Choose allowlist IDs from that sanitized list. Confirm `LOGICC_DEFAULT_MODEL` is present in both the enabled set and the allowlist.

Do **not** paste the key into chat, shell history examples, reports, screenshots, source, fixtures, or commits.

## 3. Start production build (localhost)

```bash
# Node 24.x required
node -v
npm ci
npm run build
# Bind privately — do not publish the port
PORT=3000 npm run start
```

Restart after any `.env.local` change so the server reloads configuration.

## 4. Live smoke procedure

Report only sanitized pass/fail, model ID/display name, safe error codes, and visible non-sensitive symptoms.

```text
configure Logicc mode locally
→ start production build
→ verify health
→ verify sanitized models
→ open workspace
→ send text-only prompt
→ observe streaming
→ request harmless tool
→ verify no execution before approval
→ approve
→ verify execution exactly once
→ verify safe result continuation
→ verify final response
→ cancel active stream
→ retry
```

### Checks

| Step | Expect |
|------|--------|
| `GET /api/agent/health` | `provider`/`providerId` Logicc, `ready: true`, `access: internal`, `status: ready`. No key material. |
| `GET /api/agent/models` | Sanitized approved list only; default is allowlisted. |
| Workspace UI | Provider: Logicc · Model: approved display name · Status: Ready. Anthropic BYOK field **hidden**. |
| Text-only prompt | Tokens stream; exactly one terminal completion. |
| Harmless tool (e.g. write a test file) | Approval required before execution; tool does not run while pending. |
| Approve | Tool executes **exactly once**. |
| Continuation | Model-safe result returns; final assistant response completes. |
| Cancel | Active stream cancels cleanly; retry works afterward. |
| Browser network | No `x-coderxp-byok-key`; no Logicc credential in requests. |

### Optional automated localhost helpers

With the production server already running on loopback and Logicc env configured:

```bash
npx tsx scripts/smoke-logicc-live.ts

```

These helpers report sanitized pass/fail only and must never print the API key.
